# Accessibility (a11y)

BAKLOG targets **WCAG 2.1 AA** on the dashboard ([index.html](../index.html)). SEO and Lighthouse Best Practices are tracked separately.

## CI gate (axe-core)

Every push/PR runs `tests/a11y/index-axe.test.js` via vitest. It:

1. Hydrates `index.html` into happy-dom (scripts/styles stripped).
2. Injects representative runtime DOM (table row, connection rail, fetcher chip).
3. Runs [axe-core](https://github.com/dequelabs/axe-core) (same rule pack Lighthouse uses for Accessibility).
4. **Fails** on any `serious` or `critical` violation not listed in [tests/a11y/known-violations.json](../tests/a11y/known-violations.json).
5. Logs `moderate` / `minor` violations as warnings (non-blocking).

```bash
npm test -- tests/a11y/index-axe.test.js
```

To allow a conscious deferral, add an entry to `known-violations.json`:

```json
{ "id": "color-contrast", "impact": "serious", "reason": "Chart.js canvas theming — tracker find_a11y_charts" }
```

## Manual Lighthouse pass

axe-core does not replace a real browser audit. Before a release:

1. `python server.py` and open http://localhost:8765
2. DevTools → Lighthouse → **Accessibility only**
3. Run on each view: **Dashboard**, **Library**, **Wishlist**, **itch.io**, **Connections**
4. Target score: **100** on every view

Document any remaining items in `known-violations.json` with a reason.

## What we ship

- Skip-to-main link (`#main` landmark)
- `aria-current="page"` on active view tab
- Focus trap + Escape on dialogs, filter drawer, Connections popover
- `:focus-visible` outline (amber) globally in [app.css](../app.css)
- Co-op filter as `role="radiogroup"` + `role="radio"` + `aria-checked`
- Decorative cover images: `alt=""` + `aria-hidden="true"`
- Error toast: `role="alert"` + `aria-live="assertive"`
- Muted text on `bg-slate-800`: `text-slate-400` minimum (AA 4.5:1)

## Out of scope (this pass)

- [tracker.html](../tracker.html) — internal project tracker, not user-facing product UI
- Lighthouse **SEO** and **Best Practices** categories — separate plans
- Descriptive alt text on cover thumbnails (decorative beside game name column)
