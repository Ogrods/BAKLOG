How connections work Read this once before signing in
A

Automatic browser sign-in

Steam, GOG, PlayStation, Xbox (play history), Xbox Store wishlist, Battle.net, Nintendo, Ubisoft, Epic wishlist. Click Connect on the card and a Chromium window opens automatically. Sign in normally — when the page lands on the right spot, the window closes itself and the card flips to Connected. Don't close the window manually unless you cancel.

B

Manual sign-in (paste-a-code)

Epic (library): click Open sign-in page, sign in, copy the authorizationCode you see, paste it in the card, hit Save key. We trade it for a 30-day refresh token automatically.

C

Manual API key

itch.io, IsThereAnyDeal (ITAD): open the linked settings page, generate an API key, paste it in the card, hit Save key. Their auth pages can't be automated, so this is one-time.

D

Local-only

Amazon Games: nothing to sign in to — we read the local Amazon Games launcher database on this PC. If you don't have it installed, this card just stays disconnected.

Everything is stored encrypted on this machine (OS keychain by default). Sessions expire eventually — when a fetcher fails with an auth error, the card flips to Session expired and you just click Reconnect to refresh.

Advanced

Portable master password (optional — overrides OS keychain). Most users can leave this blank.

Using OS keychain by default.

Clean up unknown games

These entries have no matching game in any loaded catalog. Common causes: a fetcher hasn't been run for that store this session, a game was removed from your library, or a connector is disconnected. Removing only deletes the personal data attached to that key; the server writes a timestamped backup to data/personal_backups/ before each save, so a wrong delete can still be restored.
