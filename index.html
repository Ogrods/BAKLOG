Clean up unknown games

These entries have no matching game in any loaded catalog. Common causes: a fetcher hasn't been run for that store this session, a game was removed from your library, or a connector is disconnected. Removing only deletes the personal data attached to that key; the server writes a timestamped backup to data/personal_backups/ before each save, so a wrong delete can still be restored.
