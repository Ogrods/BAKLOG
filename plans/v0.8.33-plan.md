## Priority 1: Debug CDP Connect Failures

### Problem

In v0.8.32 frozen builds, three stores fail:

- **Battlenet** — CDP browser window closes immediately
- **Amazon** (`amzn_web`) — connect fails silently
- **Nintendo** — fetch fails instantly

### How to diagnose

1. Launch the v0.8.32 frozen build with admin mode:
   ```powershell
   $env:BAKLOG_ADMIN="1"; .\BAKLOG.exe
   ```
2. Open http://127.0.0.1:8765/admin/
3. Click **Connect** for Battlenet
4. Watch the **Run Console** at the top of the admin page for streaming logs

### CDP stderr capture

In v0.8.32, `auth/cdp_browser.py:1587-1588` was changed from `stderr=DEVNULL` to `stderr=STDOUT`. If Chrome exits immediately, the early stderr output is captured and included in the error message (line 1597-1614). This should tell us why the browser is failing.

### Common causes to check

- Chrome/Edge not installed or wrong path
- Profile lock from another Chrome instance
- CDP port conflict
- Missing dependencies in frozen bundle (`_internal/`)

### Files

- `auth/cdp_browser.py` — `launch_persistent_profile()` at line ~1580
- `auth/runner.py` — fetcher dispatch

## Agent Onboarding Checklist

When a new agent starts a session, it should:

1. **Read** `AGENTS.md` (project rules, hard constraints)
2. **Read** `.cursor/rules/` directory (domain-specific rules)
3. **Check** `git log --oneline -20` for recent context
4. **Check** `git status` — working tree should be clean
5. **Check** CI status: `gh run list --workflow=CI --branch main --limit 3`
6. **Read** `CHANGELOG.md` for the latest release notes
7. **Read** `docs/ARCHITECTURE.md` for system design
8. **Check** `plans/` directory for any active plan files
9. **Check** `../baklog-internal/tracker.html` for progress status
10. **Run** `.\.venv\Scripts\python.exe -m pytest -x -q --timeout=30 tests/test_admin_dashboard.py` to verify tests pass locally before making changes
11. **Run** `npm test` for JS tests
12. **Run** `.\.venv\Scripts\python.exe -m ruff check` to verify lint

### PowerShell Gotchas

- Use `findstr` not `grep`/`sed`
- Use `Get-Content` not `cat`
- Python venv: `.\.venv\Scripts\python.exe` not `python`
- `gh` CLI is available for GitHub API access
