# v0.8.33 Complete Plan

## Root Cause: Dismissed ID Pruning

The publish script at `fetchers/build_free_claims.py:1464-1468` **prunes dismissed IDs** that don't exist in the current auto feed:

```python
pruned_dismissed = [
    d for d in dismissed
    if d not in blocked_set and (not auto_ids or d in auto_ids)
]
```

When the auto feed refreshes and a source changes its IDs (gamerpower, itad), old dismissed IDs get deleted. When the same game reappears with a new ID, it's no longer dismissed → user sees dupes again.

## Fix: Key-Based Dismissal

Instead of dismissing specific source IDs, dismiss by **normalized title key** (`coverLookupKey`). This way, if "Nova Lands" appears from any source with any ID, it stays dismissed.

### Changes needed:

### 1. `admin/admin.js` — `hideDuplicateSiblings()`

- Change `dismissedIds.add(id)` to `dismissedIds.add(dupKey)` where `dupKey` is the normalized title key
- Change `saveApproved()` to persist title keys instead of source IDs
