### ⚠️ Action item: `/api/proxy/` security review

- **Added in this session**: `/api/proxy/steam-search` and `/api/proxy/steam-reviews`
- **Risk**: Unrestricted proxy — any search term can be fed to Steam API
- **Mitigation**: Only proxies to `store.steampowered.com` (read-only search endpoints), no credentials forwarded. Low risk for beta but should be documented.
- **Recommendation**: Rate-limit in production if abused.
